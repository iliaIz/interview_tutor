# Stage 04: Frontend Calibration Spectrum UI

> **Статус:** ⚪ К ВЫПОЛНЕНИЮ  
> **Файлы спецификации:** `frontend/src/components/VoiceModal.tsx`, `frontend/src/components/StudyDeck.tsx`  
> **Инварианты:** Инвариант 3 (3-Tier Strictness Spectrum)

---

## 1. Архитектурная цель

Предоставить пользователю интуитивный, эстетичный и лаконичный выбор уровня строгости калибровки знаний (в пастельной гамме приложения, без перегрузки интерфейса).

---

## 2. Ключевые изменения

1. **State & LocalStorage Sync:**
   - Новый тип: `type StrictnessLevel = 'learning' | 'standard' | 'hardcore';`
   - Инициализация из `localStorage.getItem('interview_strictness_level') || 'standard'`.
   - Для `sessionType === 'tutor'` дефолтным уровнем является `'learning'`.
2. **UI-компонент селектора строгости в `VoiceModal.tsx`:**
   - Расположение: в блоке настройки лобби перед стартом сессии (Lobby stage).
   - Селектор из 3 пастельных чипов:
     - 🟢 **Обучение** (мягкий разбор, объяснение ошибок без стресса)
     - 🟡 **Собеседование L5** (реалистичный темп, зондирование пробелов)
     - 🔴 **Bar-Raiser L6** (бескомпромиссный стресс-тест отказов)
3. **Проброс в WebSocket URL:**
   - Добавление `strictness` в `URLSearchParams` при открытии сокета живого диалога.
4. **Синхронизация с карточкой вопроса (`StudyDeck.tsx`):**
   - Передача выбранного уровня строгости при запуске сессии тьютора прямо из карточки.

---

## 3. Критерии готовности (Acceptance Criteria)
- [ ] В лобби `VoiceModal` отображается переключатель строгости.
- [ ] Выбор сохраняется в `localStorage` и восстанавливается при повторном открытии.
- [ ] Параметр `strictness` передается на бэкенд в URL WebSocket.
