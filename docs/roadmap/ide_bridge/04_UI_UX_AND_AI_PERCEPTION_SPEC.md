## 1. Пользовательский интерфейс (UI/UX)

### 1.1. Интеграция в панель инструментов (`WorkspaceHeaderBar.tsx`)
В хедере редактора кода добавляется блок управления IDE-мостом:

1. **Когда мост отключен (`status === 'disconnected'`):**
   - Отображается элегантная кнопка:
     `[ 💻 Решать в IDE ]`
   - При клике открывается модальное окно `IdeBridgeModal`.

2. **Когда мост подключен (`status === 'connected'`):**
   - Отображается активный статус:
     `[ 🟢 IntelliJ: Активна ]`
   - При наведении в тултипе показывается:
     *«Синхронизировано с локальной папкой ~/tutor-workspace/rate-limiter. Все сохранения в IntelliJ автоматически видит ИИ-напарник.»*
   - Клик по статусу открывает модалку с кнопкой отключения или повторного скачивания архива.

- `CONNECTED`: Зелёная плашка с галочкой:
  *«🎉 IntelliJ IDEA успешно подключена! Можете закрыть это окно. Код синхронизируется в реальном времени.»*

## 2. Интеграция с восприятием ИИ (Gemini Live Perception)

### 2.1. Мгновенная доставка контекста (< 100 мс)
В файле [`frontend/src/services/DeicticGroundingManager.ts`](file:///home/djelu/projects/interview_tutor/frontend/src/services/DeicticGroundingManager.ts) уже реализована функция:
```typescript
export function createCodeFrame(
  code: string,
  fileName?: string,
  language?: string,
  isHandoverFlush?: boolean
): any;
```

При поступлении события `FILE_UPDATED` из моста:
1. Хук `useIdeBridge` обновляет файл в Zustand `practiceWorkspaceFiles`.
2. Автоматически переключается `activeFilePath` на изменённый файл.
3. Формируется фрейм:
   ```typescript
   const frame = createCodeFrame(payload.content, payload.path, 'java');
   ```
4. Фрейм мгновенно отправляется в активную сессию Gemini Live WebSocket (`screen_context_sync`).
5. **Результат**: когда пользователь говорит в гарнитуру: *«Посмотри на метод tryAcquire, нет ли тут гонки?»*, Gemini Live уже располагает полным текстом метода, только что сохранённого в IntelliJ.

---

### 2.2. Синхронизация ошибок компиляции и тестов
Если пользователь запускает проверку тестов платформы:
1. Вывод песочницы (`SandboxExecutionResponse.syntaxErrors` или `testResults[].failureReason`) форматируется как терминальный фокус:
   ```typescript
   createDeicticFocusPrompt({
     zone: 'terminal',
     text: failureMessage
   });
   ```
2. ИИ-напарник мгновенно реагирует голосом на упавший тест:
   *«Тест testConcurrentAcquireStress упал с таймаутом. Похоже, потоки заблокировались на не освобождённом локе.»*

## 3. Схема состояний FSM моста (`useIdeBridge`)

```
   ┌──────────────┐
   │ DISCONNECTED │◄───────────────────────────┐
   └──────┬───────┘                            │
          │ connect()                          │ Обрыв связи
          ▼                                    │
   ┌──────────────┐                            │
   │  CONNECTING  │                            │
   └──────┬───────┘                            │
          │ HANDSHAKE_ACK                      │
          ▼                                    │
   ┌──────────────┐   FILE_UPDATED             │
   │  CONNECTED   │──────────────────┐         │
   └──────▲───────┘                  ▼         │
          │                   ┌──────────────┐ │
          └───────────────────┤   SYNCING    │─┘
             debounce flush   └──────────────┘
```
