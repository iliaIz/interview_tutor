## Фаза 1: Zero-Dependency Bridge Core (`bridge.mjs`)

### Цель:
Создать ультралегковесный скрипт синхронизации на нативном Node.js (без внешних зависимостей в `package.json`), способный отслеживать файлы в рабочей папке и избегать циклических перезаписей.

### Задачи:
1. Реализовать `bridge.mjs` с поддержкой Node.js 20/22 ESM.
2. Внедрить нативный файловый вотчер через `node:fs` / `fs.watch` с рекурсивным обходом папки `src/`.
3. Реализовать фильтрацию системного мусора: `.idea/`, `target/`, `.git/`, `.DS_Store`, временных файлов `*~`, `*.swp`.
4. Реализовать trailing debounce (120 мс) для склеивания множественных событий сохранения при рефакторинге в IDE.
5. Реализовать механизм `Hash Fence` на базе `node:crypto` (SHA-256 или CRC32) для отсечения неизменённых файлов.

### Шлюз качества (GATE 1):
- [ ] `bridge.mjs` запускается командой `node bridge.mjs` без вызова `npm install` (0 внешних npm-пакетов).
- [ ] Потребление оперативной памяти процесса $\le 20$ МБ.
- [ ] Нажатие `Ctrl+S` в любом `.java` файле генерирует ровно одно событие изменения файла за $< 50$ мс.
- [ ] Изменения внутри `.idea/` и `target/` полностью игнорируются вотчером.

## Фаза 3: Loopback WebSocket Server & Handshake Protocol

### Цель:
Реализовать двусторонний сетевой контракт между локальным процессом `bridge.mjs` и браузером по адресу `ws://127.0.0.1:41789`.

### Задачи:
1. Поднять легковесный WebSocket-сервер на базе нативного `node:http` внутри `bridge.mjs`.
2. Реализовать рукопожатие `HELLO` / `HANDSHAKE_ACK` с проверкой допустимых Origin (`http://localhost:*`, `https://*.domain`).
3. Реализовать обработку входящих событий:
   - `INIT_CHALLENGE`: первоначальная сверка файлов задачи.
   - `FILE_UPDATED` (из IDE в Браузер): отправка нового текста файла с `origin: 'ide'`.
   - `FILE_UPDATED` (из Браузера в IDE): запись на локальный диск с установкой `inFlightWrites` для EchoGuard.
4. Реализовать Heartbeat / Ping-Pong для мгновенного детектирования разрыва связи.

### Шлюз качества (GATE 3):
- [ ] Сервер слушает строго `127.0.0.1:41789` (внешние подключения заблокированы).
- [ ] При сохранении файла в IDE браузер получает событие за $< 15$ мс по loopback-интерфейсу.
- [ ] При отправке файла из браузера на диск EchoGuard предотвращает повторную отправку в браузер (0 циклов эха).
