---

## 1. Проблема и цели этапа

В ходе аудита пользовательского опыта были выявлены две ключевые проблемы:
1. **Проблема скрытности в каталоге (Discovery Defect):**
   В `PracticeCatalog.tsx` вкладка `refactoring_kata` была 7-м элементом в горизонтальном скролле `overflow-x-auto`. На экранах ноутбуков и планшетов она уходила за правый край, из-за чего пользователь не мог найти задачи без явного поиска.
2. **Отсутствие специализированной среды для Code Review:**
   Существующие экраны задач рассчитаны либо на один файл решения (`Solution.java`), либо на прогон мутационных тестов. Для рефакторинга необходим мультифайловый интерфейс с одновременным отображением запахов кода, грязного легаси-кода, характеризационных тестов и статуса прохождения 3 шлюзов верификации.

**Цель Фазы 4:** Вынести Refactoring Arena на главный экран каталога Практики в виде премиальной карточки первого уровня и создать эргономичную студию `RefactoringArenaStudio.tsx` с разделением ответственности ($\le 350$ строк на компонент).

1. **Флагманский баннер первого уровня:**
   В верхней сетке режимов (рядом с `Spring Transactions Lab`, `Testing & Mutation` и `System Design`) добавляется карточка:
   - **Заголовок:** `Refactoring & Code Review Arena`
   - **Подзаголовок:** `24 канонические задачи с собеседований BigTech & FinTech (L0–L3)`

   - **Теги компаний:** `Т-Банк`, `Яндекс`, `Ozon`, `Stripe`, `Netflix`, `Amazon`
   - **Фича:** `Голосовой Bar-Raiser ассистент`

   Возможность мгновенной фильтрации каталога по грейдам, архитектурным темам (Loom, Concurrency, Clean Code, Hexagonal, Outbox) и статусу решения.

## 3. Архитектура экрана `RefactoringArenaStudio.tsx`

Компонент декомпозируется на независимые модули ($\le 300$ строк каждый) в соответствии с Rule 8:

```
frontend/src/components/refactoring/
├── RefactoringArenaStudio.tsx            # Корневой контейнер и роутинг сессии
├── RefactoringSmellChecklistPanel.tsx    # Панель запахов кода с отметками голосового ИИ
├── RefactoringMonacoWorkspace.tsx       # Многофайловый Monaco Editor (Java 21)
├── RefactoringVerificationModal.tsx     # Детализация 3-Gate верификатора (AST, тесты, телеметрия)
└── RefactoringVoiceBarRaiserBar.tsx     # Парящая панель голосового ассистента с визуализатором волны
```

## 4. Стилистика и эстетика (UI/UX Invariants)

- **Палитра:** Мягкая пастельная роскошь (`#FFF0F5`, нежно-лавандовые акценты, стеклянный морфизм `backdrop-blur-md`, теплый розовый ореол активности микрофона).
- **Высота вьюпорта:** Строго `100dvh` (`h-[calc(100dvh-4rem)]`), исключающий скачки страницы при появлении мобильной клавиатуры.
- **Scroll Lock:** Использование `useBodyScrollLock` со счетчиком ссылок при открытии модальных окон телеметрии или разбора ошибок.
