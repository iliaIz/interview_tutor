# Навигационный хаб и архитектурный индекс: Управление контекстом в Gemini 3.8 Live

> **Назначение документа:** Центральный маршрутизатор базы знаний и семантический индекс для ИИ-агентов и инженеров.  
> **Целевой стек:** Google Multimodal Live API (`BidiGenerateContent`), WebSocket RFC 6455, SDK `@google/genai` (v2.3.0+), Web Audio API.  
> **Модели:** `gemini-3.8-live`, `gemini-3.8-live-extended-thinking`, `gemini-3.1-flash-live-preview`.

---

## 🗺️ Топология базы знаний (Карта модулей)

База знаний декомпозирована на **4 ортогональных доменных модуля, сфокусированных строго на архитектуре и управлении контекстом модели**. Каждый модуль самодостаточен, содержит полную цепочку причинно-следственных связей своего домена и оптимизирован для чтения агентом за **один вызов** инструмента без потери внимания и усечений.

## ⚖️ Сводная матрица архитектурных инвариантов («Как ДЕЛАТЬ» vs «Как НЕ ДЕЛАТЬ»)

```
+-----------------------------------------------------------------------------------------------------------------------+
| ОБЛАСТЬ              | ❌ АНТИПАТТЕРН (Симптом / Костыль)             | ✅ КАНОНИЧЕСКИЙ СТАНДАРТ (Первопричина)                 |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| Заземление кода      | Посев файлов через clientContent.turns        | Ядро (3k–12k токенов) в systemInstruction (XML CDATA) |
|                      | на нулевом ходу с псевдо-ответом модели       | Периферийные файлы динамически через read_file        |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| Кэширование          | Явный cachedContent для баз < 32 000 токенов  | Статический префикс в systemInstruction:              |
|                      | (гарантированная ошибка 400 Validation)       | неявное кэширование TPU v5e/v6e работает автоматически|
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| Непрерывность сессий | Ручной реплей стенограммы реплик из памяти    | Нативный Session Resumption: сохранение newHandle     |
|                      | (разрушает просодию, вызывает гонки VAD)      | строго при resumable: true, передача в setup.handle   |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| 10-минутный лимит    | Ожидание принудительного разрыва сокета       | Перехват goAway.timeLeft на 9-й минуте и              |
|                      | по таймауту на 600-й секунде                  | упреждающий бесшовный Hot Handoff на сокет B          |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| Режим инструментов   | Синхронные BLOCKING функции                   | Строго behavior: "NON_BLOCKING". Модель озвучивает   |
|                      | (создают мертвые паузы тишины в 1–3 секунды)  | речевые связки во время асинхронного исполнения       |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| Планирование tools   | Стандартный возврат scheduling: "WHEN_IDLE"   | Строго scheduling: "SILENT" для визуальных мутаций    |
|                      | для мутаций экрана (паразитное речевое эхо)   | интерфейса доски, фонового анализа и логов            |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| Окончание реплики    | Опора исключительно на turnComplete: true     | Предикат готовности: буфер пуст + очередь tools = 0   |
|                      | (в рассуждающих моделях CoT продолжается!)    | + interactionStatus == IDLE                           |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| Эндпоинтинг речи     | Отправка audioStreamEnd: true при паузах      | Непрерывный PCM-стрим 16 кГц, сквозной серверный VAD  |
|                      | (крах конвейера вокодера: Close 1011)         | с калибровкой silenceDurationMs: 400–700 ms           |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| Граница хода в UI    | Зажигать «Слушаю» сразу по turnComplete       | Расчет задержки опустошения ЦАП T_drain (200–500 мс)  |
|                      | (хвост фразы попадает в микрофон -> эхо-barge)| до механического затихания динамика                   |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| Прерывание (Barge-In)| Мгновенное обнуление указателя воспроизведения| Активация 5-мс спада огибающей Ханна (L_ramp = 120),  |
|                      | (ступенька волны вызывает щелчок Хевисайда)   | подавляющей высокочастотный акустический щелчок       |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
| Координация медиа    | Отправка аудиочанков во время исполнения tools| Программный мьютекс: приостановка realtimeInput       |
|                      | (крах сессии по ошибке 1008 Policy Violation) | на интервале между получением toolCall и toolResponse |
+----------------------+-----------------------------------------------+-------------------------------------------------------+
```
