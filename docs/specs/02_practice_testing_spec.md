## 1. Назначение и концепция
Режим практического написания надежных тестов (JUnit 5, AssertJ, Mockito, Awaitility) и уничтожения мутантов через мутационное тестирование PIT (Pitest). Цель — довести Mutation Score выше заданного порога (>= 85-90%) без раздувания бесполезного line coverage.

## 3. Активный Компас: Testing Compass
* **Компонент**: `TestingCompassSheet.tsx` (Горячая клавиша: `Ctrl + /`).
* **5 Золотых Заповедей**:
  1. **Паттерн AAA (Arrange — Act — Assert)**: Четкое разделение подготовки, единственного действия и строгой проверки через AssertJ.
  2. **Тест как охотник на мутантов (Adversary Thinking)**: Тестирование граничных значений, проверка падения теста при смене операторов (`>` на `>=`).
  3. **Состояние против Взаимодействия (State vs Interaction)**: Проверка возвращаемого значения вместо избыточного `verify()`. `verify()` только для `void`-команд.
  4. **Закон Моков Фаулера (Fowler's Law)**: Мокать только внешние границы (I/O, внешние HTTP API). Доменные сущности, Record и DTO создаются через `new`.
  5. **Детерминизм и Виртуальное Время**: Никакого `Thread.sleep()`. Инжекция `java.time.Clock` и мгновенные проверки за 0 мс через `Clock.fixed()`.

## 4. Рабочее пространство (Non-Modal Integrated Standard)
* **Интегрированная вкладка Доски**: Вкладка **`[ 🎨 Доска ИИ (vN) ]`** расположена в шапке редактора рядом с файлами кода с шорткатом **`Alt + W`**.
* **Индикатор новизны**: При получении `update_whiteboard` от ИИ вкладка подсвечивается пульсирующим бейджем, а на экране появляется Toast-уведомление.
* **Полноценная поверхность**: Включает `CodeArtifactTimeline`, переключатель Diff, подсветку синтаксиса Java, пояснение напарника и выделенные строки (`highlightLines`).
* **In-Memory Sandbox Console**: Запуск тестов и расчет Mutation Score за < 80 мс без перезапуска JVM.
