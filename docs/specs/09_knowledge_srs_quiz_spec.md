# 09. Knowledge Engine: Theory, SRS Study Deck & Exam Quizzes

> **Версия**: 2.0 (Сентябрь 2026)  
> **Статус**: Production Ready  
> **Роут**: `/` -> Студия: Вкладка `theory` (включая `topics`, `questions`, `study`, `quiz`)

---

## 1. Назначение и концепция
База фундаментальных инженерных знаний и когнитивный тренажер долговременной памяти (Long-Term Retention). Объединяет каталог тем, структурированные вопросы с эталонными ответами, алгоритм интервального повторения Лейтнера (Spaced Repetition System / SRS), режим сертификационного тестирования на время (Exam Quiz) и синтез подкастов для аудиального обучения на ходу.

---

## 2. Подсистемы и архитектурные компоненты

### 2.1. Каталог тем и Проводник вопросов (`TopicSelector` & `QuestionExplorer`)
* **Роуты**: `/api/topics` и `/api/topics/:id/questions`.
* **Функционал**:
  * Иерархическая группировка по доменам (Java Core, Spring, Concurrency, Database, Distributed Systems, Testing).
  * Карточки вопросов с тремя уровнями погружения: краткая выжимка (TL;DR), развернутый эталонный ответ и код под микроскопом.
  * Интеграция с закладками шпаргалки (CheatSheet Bookmarks).

### 2.2. Колода интервального повторения (`StudyDeck` — Leitner SRS)
* **Алгоритм**: Модифицированная 5-ячеечная система Лейтнера (Boxes 1..5) с экспоненциальными интервалами повторения ($2^{box-1}$ дней).
* **Принцип Active Recall**: Карточка изначально скрывает ответ. Кандидат формулирует ответ вслух или мысленно, затем нажимает «Показать ответ» и оценивает качество воспоминания (`Снова`, `Трудно`, `Хорошо`, `Легко`).
* **Оптимизация под мобильные устройства**: Поддержка свайп-жестов (влево — забыл, вправо — запомнил), 100dvh standard.

### 2.3. Экзаменационный квиз (`ExamQuiz`)
* **Формат**: Симуляция сертификационных экзаменов (Oracle OCP / Spring Certified Professional / FAANG Screening).
* **Ограничение по времени**: Таймер с динамической цветовой индикацией остатка времени.
* **Анализ результатов**: Детальный разбор ошибок с цитированием спецификации языка Java (JLS 21) и исходного кода Spring Framework.

### 2.4. Аудио-рекап и подкасты (`AudioPlayerBar` & `AudioRecapModal`)
* **Синтез аудио**: Генерация диалогового рекапа темы через Gemini TTS (`${GEMINI_TTS_MODEL}`) в фоновом режиме через `LiteLLM_Proxy`.
* **Плеер**: Глобальный плавающий плеер внизу страницы (`AudioPlayerBar`), синхронизированный со стенограммой и возможностью регулировки скорости (1.0x, 1.25x, 1.5x, 2.0x).

---

## 3. Инварианты надежности и производительности
1. **Offline-First кеширование карточек**: Загруженная колода кешируется в памяти браузера, позволяя учить карточки в метро или при нестабильном соединении.
2. **Синхронизация прогресса**: Прогресс ячеек Лейтнера отправляется на сервер пакетами (debounced batch sync), исключая перегрузку API при быстрых ответах.
3. **Фоновое воспроизведение**: При переключении между разделами воспроизведение аудиоподкаста не прерывается благодаря изоляции глобального `AudioPlayerBar`.
