# 01. Mock Interview Specification

## Назначение
Режим имитации технического собеседования (Mock Interview) для калибровки грейдов L4 (Middle), L5 (Senior), L6 (Staff) по стеку Java, Spring Boot и распределенным системам.

## Диалоговый движок
* **Транспорт**: WebSocket `/ws/live?sessionType=interview` через LiteLLM Proxy.
* **Модель по умолчанию**: `${GEMINI_LIVE_MODEL}` (`gemini-live-v3`).
* **Роль ИИ**: FAANG Interviewer (Google / Meta / Amazon).
* **Стиль диалога**: Требовательный, калибровочный, следующий модели STAR / PREP / Rule of 3.

## Инструменты модели (Tools)
1. `update_whiteboard`: Демонстрация контрпримеров или разбора архитектурных конструкций на доске.
2. `submit_interview_evaluation`: Фиксация баллов, штрафов (deductions) и калибровочного вердикта (Hiring Committee).
   * **First-Turn Lock**: Запрещен вызов на нулевом ходу (приветствие).

## Интерфейс и рабочее пространство
* **Формат доски (Whiteboard)**: Встроенная правая панель (Docked Split Stage).
* **Запрет оверлеев**: Никаких плавающих модалок `z-50`, перекрывающих кнопки завершения звонка и стенограмму.
* **Мобильный режим**: Вкладки `[ 🎙️ Собеседование ]` / `[ 🎨 Доска ИИ ]`.
