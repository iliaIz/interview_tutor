# 🚀 InterviewTutor IntelliJ Companion Bridge

Инструкция по решению задачи в **IntelliJ IDEA** с поддержкой голосового ИИ-напарника.

---

## 3 простых шага для старта:

### 1. Откройте проект в IntelliJ IDEA
* В меню выберите: **File $\rightarrow$ Open** (или Открыть).
* Выберите эту папку.
* IntelliJ автоматически распознает стандартный `pom.xml` (Java 21, JUnit 5 Jupiter, AssertJ).

### 2. Запустите синхронизацию:
* **Linux / macOS**: запустите `./run-bridge.sh` (или `node bridge.mjs`).
* **Windows**: дважды кликните по файлу `run-bridge.cmd`.

> 💡 *Установка зависимостей (`npm install`) НЕ требуется. Мост использует встроенные возможности Node.js.*

### 3. Решайте задачу:
* Пишите код в IntelliJ IDEA и нажимайте `Ctrl+S` (или работает автосохранение).
* Мост передаёт правки в веб-интерфейс за **< 50 мс**.
* ИИ-напарник (Gemini Live) слышит вас в гарнитуре и видит ваш актуальный код.
* Локальные юнит-тесты запускаются прямо в IntelliJ кликом по зелёной стрелке возле `@Test`.
* Финальную проверку запускайте по кнопке «Проверить» в веб-интерфейсе платформы.
